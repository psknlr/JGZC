# 安全审查与随访

安全审查**最后跑**，跑在已经组装好的方案上，顺序固定：

```
禁忌证 → 药物相互作用 → 肾功能 → 低钙风险 → 跌倒风险 → 依从性 → 随访节点
```

## 顺序即设计

在不知道肾功能之前查相互作用，产出的是一份关于**本来就不该给的药**的漂亮报告。
钙的门必须在任何抗骨吸收药下达**之前**关上，而不是之后——顺序颠倒是抗骨吸收药物
相关严重低钙血症最主要的可预防原因。

## 平台的两条自律

**漏跑的检查必须被报成漏跑。** `SafetyAndFollowup` 的 schema 要求 `checks_run`
包含全部七项，缺项的输出被拒收，该 Agent 记为 `blocked`。一份有静默缺口的安全报告，
比没有报告更危险——因为它看起来是完整的。

**阻断即阻断。** `blocking` 非空时，整次运行标记为 `needs_action`（CLI 退出码 2），
方案里的药物卡片被打上 ⛔ 并写明是哪几条挡住了它。

## 各项检查

### 1 禁忌证
* 汇总循证决策 Agent 判为 `excluded` 的方案性条目，按 `action` 去重后逐条列出排除依据
  （多部指南一致排除时合并显示，不重复计数）；
* 说明书级禁忌：近 12 个月心梗/卒中 → 罗莫索单抗禁用（**阻断**）；活动性食管疾病或
  不能保持直立 → 口服双膦酸盐剂型禁忌；骨骼放疗史/恶性肿瘤 → 促骨形成药物需先排除；
  待处理拔牙或牙病 → 先处理口腔病灶再启动抗骨吸收治疗。

### 2 药物相互作用
基于 `safety/drugs.py` 的规则表，每条带临床后果与处置：钙剂 × 左甲状腺素（螯合，间隔 4 h）、
钙剂 × 喹诺酮类、钙剂 × 口服双膦酸盐、钙剂 × 铁剂、PPI × 双膦酸盐、
活性维生素 D × 钙剂（高钙风险）、活血类中成药 × 抗凝药、噻嗪类 × 钙剂。

**未识别的药物是一项高风险发现**，不是一个可以忽略的空值：相互作用与跌倒风险统计
不包含它们，必须由临床药师人工核对后重跑。

### 3 肾功能
| 药物类别 | 门槛 | 判定 |
| --- | --- | --- |
| 双膦酸盐 | eGFR < 35 | 不推荐 |
| 地舒单抗 | eGFR < 35 | 可用但需强化血钙监测 |
| 非甾体抗炎药 | eGFR < 45 | 老年人应避免 |
| 活性维生素 D | eGFR < 45 | 需按钙磷 PTH 调整，肾科共管 |

**eGFR 未知本身是阻断项**：拟用抗骨吸收药物而没有肾功能，用药前必须先查。
eGFR < 45 时另加一条"需鉴别 CKD-MBD"——把肾性骨病当作原发骨质疏松治疗，既无效又延误。

### 4 低钙风险
* 拟用抗骨吸收治疗而**未查校正血钙** → 阻断；
* 拟用抗骨吸收治疗而**未查 25-OH-D** → 阻断；
* 已知低钙未纠正 → 阻断；
* 维生素 D 缺乏 → 高风险，按常规每日剂量补足并复查（不用大剂量冲击）；
* eGFR < 35 且走地舒单抗路径 → 说明书警示级别的严重低钙风险，附早期血钙复查安排与
  患者自我监测症状交代（手足抽搐、口周麻木）。

### 5 跌倒风险
统计跌倒风险药物（苯二氮䓬、Z 类、抗胆碱能、抗精神病、抗抑郁、阿片、降压、利尿、SGLT2）
与骨骼有害药物（糖皮质激素、噻唑烷二酮）；高跌倒风险却没有居家环境记录时给出提示。
减停计划必须渐进——苯二氮䓬类不可骤停。

### 6 依从性
多重用药、认知障碍或独居导致的服药管理缺口、**处方遗漏**（已诊断骨质疏松却没有
抗骨质疏松药物；钙与维 D 属基础用药，不计入），以及地舒单抗的给药时间——
后者不是依从性问题而是安全问题，延迟即进入反跳风险窗口。

### 7 随访节点

按这位患者**将要接受什么**生成，落到四档：

| 档 | 内容取决于 |
| --- | --- |
| 即刻 | 用药前置化验；未做椎体影像则加做；未测 ASMI 则补测（让三套标准收敛） |
| 3 个月 | 抗骨吸收治疗 → 复查血钙与维 D；CKD 地舒单抗路径 → 额外 1～2 周与 1 个月血钙；握力与起坐复测；运动进阶；蛋白摄入达标；跌倒日记与用药重整落实 |
| 6 个月 | 肌少症标准重判；肾功能与电解质；营养复评；减药进度；地舒单抗按期给药并预约下一次 |
| 12 个月 | DXA 复查；ASMI 复测；五轴风险重评；疗程与药物假期决策 |

用中成药或有中医证型记录者，3 个月加肝功能复查（部分补肾壮骨类制剂有肝损伤报告），
12 个月加证型复诊。

## 不生成剂量

给药方法（空腹、200 mL 白水、服后直立 30 分钟、与钙铁镁铝制剂间隔）、监测间隔、
疗程上限都是安全信息，会写。"这位患者给多少毫克"是医师的决定，平台不产生，
表述层如果产生了会被整段丢弃（见 [LIMITATIONS.md](LIMITATIONS.md)）。
