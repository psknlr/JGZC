# 骨肌联合诊断

## 为什么合成一次调用

同一项测量服务多个诊断：5 次起坐 16 s 既是肌少症的躯体功能判据、又是跌倒风险标志、
还通过跌倒抬高骨折风险。分成两次会诊会问两遍、只用一遍。

而**共病本身是独立诊断**：骨质疏松合并肌少症者的跌倒、骨折、失能与死亡风险高于任一单病，
且有一套两病共享的干预内核（抗阻训练、蛋白质、维生素 D），单病路径不会开出这套处方。

## 骨质疏松

两个决策分开做，因为它们回答不同的问题：

**是不是骨质疏松？**

1. 髋部或椎体脆性骨折 → 临床诊断成立，**不依赖骨密度**；
2. T ≤ -2.5（绝经后女性、50 岁以上男性）→ 成立；
3. 低骨量 + 肱骨近端/骨盆/前臂脆性骨折 → 成立；
4. T 在 -1.0 ~ -2.5 → 低骨量；
5. 无 DXA 且无诊断性部位骨折 → 无法判定（不是"正常"）。

**T 值取哪个部位？** 存在椎体骨折或高龄退变时，腰椎测值会被抬高，此时改以股骨颈/全髋为准，
并把这次替换写进 `caveats`。参考病例：腰椎 T=-2.9 被股骨颈 T=-2.6 取代，理由显示在界面上。
注意这条**降低**了 T 值的绝对值——它不是为了让诊断更容易，而是为了让读数可信。

**有多高的风险？** 极高骨折风险由指南分层规则判定（近 12 个月内骨折、治疗中骨折、
多发骨折、既往髋部或椎体骨折、T ≤ -3.0、高跌倒风险、长期激素），每一条都作为
具名驱动因素输出。这一层决定**先用哪类药**，而"是不是骨质疏松"不决定。

## 肌少症：三套标准全跑

| | AWGS 2019 | EWGSOP2 | GLIS 2024 |
| --- | --- | --- | --- |
| 握力切点 | 男<28 / 女<18 kg | 男<27 / 女<16 kg | 借用 AWGS |
| 起坐 | ≥12 s 记为**功能**下降 | >15 s 记为**肌力**下降 | ≥12 s（功能，不参与诊断） |
| 步速 | <1.0 m/s | ≤0.8 m/s（严重程度） | — |
| 肌量 ASMI | 男<7.0 / 女<5.4（DXA） | 男<7.0 / 女<5.5，或 ASM 男<20/女<15 kg | 借用 AWGS |
| 结构 | 肌量 +（肌力或功能） | 肌力 → 肌量确诊 → 功能分级 | **肌量为必备核心** |
| 缺肌量时 | 可能肌少症，可先干预 | probable，可先干预 | 不能确诊 |

三者不只是数字不同，**对"肌少症是什么"的看法不同**。所以平台不选一套，
而是三套都判、都列出依据，并解释分歧从哪来。

参考病例（78 岁女性，握力 17 kg，5 次起坐 16 s，未测肌量）：

```
AWGS 2019（亚洲）          可能肌少症（可先行干预）
    依据：肌力或躯体功能下降、肌量未测
EWGSOP2（欧洲）            可能肌少症（肌力已下降，待肌量确诊）
    依据：肌力下降、肌量未证实
GLIS 2024（全球概念框架）   无法判定（关键测量缺失）
    依据：GLIS 以肌量减少为必备核心要素，未测肌量即不能作出确定性诊断
```

自动生成的分歧说明：

* 握力 17 kg 落在切点之间：低于 AWGS 的 18，但未低于 EWGSOP2 的 16；
* EWGSOP2 把 5 次起坐用作**肌力**替代判据，AWGS 把它算作**躯体功能**——
  同一项测量在两套标准里归属不同的轴；
* 肌量未测是本次分歧的主因，补测 ASMI 可让三套标准收敛。

反方向的例子（`gc_male`，握力 27.5 kg，ASMI 已测且偏低）：AWGS 与 GLIS 判为肌少症，
EWGSOP2 判为未达标准——因为 27.5 低于 28 却不低于 27，EWGSOP2 的流程根本没有启动。

## 组件标志的回写规则

下游风险模型需要"这位患者的肌力低不低"，而不是"在 AWGS 下低不低"。所以：

* 任一标准判为低 → `low_muscle_strength = True`；
* 全部标准都无法判定 → 该事实**不写**（保持未知，而不是写 False）；
* 其余情况 → `False`。

同理 `low_physical_performance`、`low_muscle_mass`、`muscle_mass_measured`。
"不写"这一档是关键：它让下游的三值逻辑能区分"测了是正常"和"没测"。

## 共病判定

| 状态 | 条件 |
| --- | --- |
| `confirmed` | 骨质疏松成立 + 任一标准确诊肌少症 |
| `probable` | 骨质疏松成立 + 肌少症达到"可能"层级 |
| `bone_only` / `muscle_only` / `neither` | 其余 |

`probable` 也会触发共病管理路径。要求确诊才给联合方案，等于把最需要早期干预的人挡在门外——
而两病共享的干预（抗阻训练、蛋白、维生素 D）恰恰没有等待的理由。
